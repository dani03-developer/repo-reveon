REVEON | La belleza es responsable 🦊

REVEON es un proyecto de e-commerce de moda ética y sustentable, especializado en accesorios de lujo consciente. Este sitio web fue desarrollado como proyecto final, aplicando las mejores prácticas de desarrollo web front-end, diseño responsivo y optimización SEO.

🌿 Concepto del Proyecto

REVEON nace de la intersección entre la ética y la estética. Inspirado en la adaptabilidad y elegancia del zorro ártico, el sitio ofrece una experiencia de usuario minimalista y sofisticada. La marca se centra en la "Slow Fashion", promoviendo materiales orgánicos y diseños atemporales.

🎨 Proceso de Diseño (UI/UX)

La identidad de REVEON se construyó bajo el concepto de "Lujo Consciente", utilizando herramientas de diseño profesional para garantizar una experiencia de usuario fluida y estética.

Design System & Wireframing

Para este proyecto, se desarrolló un sistema de diseño que incluye:

Wireframes de Alta Fidelidad: Estructuración de la jerarquía visual antes del código.

Tipografía Elegante: Combinación de Inter para cuerpo y Pinyon Script para acentos.

Paleta Orgánica: Tonos tierra y verdes musgo que evocan sustentabilidad.

🔗 Ver proyecto y Wireframes en Figma: https://www.figma.com/design/hDkGYqZIwsfyVaRgHoCZ4J/Wireframing-Reveon?node-id=77-432&t=X30udJRV6tgj4LsE-1

🚀 Tecnologías Utilizadas

Figma: Diseño de interfaz y prototipado.

HTML5: Estructura semántica avanzada para mejorar la accesibilidad y el SEO.

CSS3 & SASS: Estilización avanzada utilizando variables, mixins, anidamiento y una arquitectura de archivos escalable.

Bootstrap 5: Framework utilizado para agilizar el sistema de grillas y componentes como la Navbar y el Carrusel.

Diseño Responsivo: Adaptación completa a dispositivos móviles, tablets y desktops (Mobile First).

Animaciones CSS: Implementación de keyframes para efectos de flotación y transiciones suaves.

📂 Estructura del Sitio

El sitio consta de 5 secciones principales:

Inicio (Index): Portada de marca, video promocional y grid de productos destacados.

Catálogo: Galería completa de productos con efectos hover y filtros visuales.

Nosotros: Historia de la marca, concepto del zorro ártico y valores de sustentabilidad.

Help & Info: Sección de preguntas frecuentes, envíos y políticas de devolución.

Contacto: Formulario de contacto integrado con diseño adaptativo.

🛠️ Instalación y Uso Local

Si deseas clonar este proyecto y ejecutarlo en tu máquina local:

Clona el repositorio:

git clone (https://github.com/dani03-developer/repo-reveon.git)


Navega a la carpeta del proyecto:

cd repo-reveon


Abre el archivo index.html en tu navegador o utiliza la extensión Live Server de VS Code.
